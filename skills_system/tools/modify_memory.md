# 背景 / 運作原理
長期記憶依 `memory/` 目錄下三個檔案分別儲存：
* `semantic.md`（語意記憶）：不隨時間變化的事實、定義、規則、使用者偏好。
* `episodic.md`（情節記憶）：特定時間點發生的事件、錯誤、專案經驗。
* `procedural.md`（程序記憶）：操作流程、SOP、執行順序等「怎麼做」的規則。

本工具只接受單一格式化字串，由後端依「問題種類」標籤自動決定寫入哪一個檔案，Agent 不需自行判斷該寫入哪個檔案。

# 語法 / 參數規範
* 唯一參數為一段字串，格式固定為：`[問題種類] | [問題描述] | [解決方法或結論]`。
* `問題種類` 僅能使用以下 5 種標籤之一，禁止自創其他標籤名稱：偏好問題、錯誤執行、工具使用、專案經驗、其他。
* 標籤 → 檔案的對應規則（Tier 1 精確比對，Tier 2 為關鍵字備援，避免因標籤誤寫而遺失記憶）：
  * `工具使用` → procedural
  * `錯誤執行`、`專案經驗` → episodic
  * `偏好問題` → procedural（属於「往後應如何應對」的持續性指令，而非單純事實）
  * `其他` → semantic（預設）
  * 若標籤不在上述 5 者之中，依關鍵字判斷：含「流程/步驟/規範/SOP/程序/風格/溝通/偏好/習慣」→ procedural；含「事件/發生/錯誤/失敗/異常/經驗」→ episodic；皆不符 → semantic。

# 執行步驟 (Steps)
1. 接收格式化字串，檢查非空。
2. 取出開頭時間戳記與「問題種類」標籤。
3. 依上述對應規則決定目標檔案（`memory/semantic.md` / `episodic.md` / `procedural.md`）。
4. 附加寫入該檔案；若標籤不在標準 5 種之內，額外回傳 `[WARN]` 提示已依關鍵字規則歸類。

# 範例 (Examples)
* `EXECUTE: modify_memory_cmd.py "偏好問題 | 使用者偏好繁體中文 | 後續回答優先使用繁體中文"`
* `EXECUTE: modify_memory_cmd.py "錯誤執行 | ROS2 launch 缺少 config.yaml | 補齊設定後成功啟動"`

# 異常處理 (Edge Cases)
* 內容為空時回傳 `[ERROR] 記憶內容不可為空`。
* 僅當使用者明確要求（如「記住這件事」「寫入記憶」）才可呼叫本工具，禁止寫入無意義對話、重複內容、過長 log、敏感資訊或未確認推測。
