# 背景 / 運作原理
包裝系統 `find -iname`，用於依檔名關鍵字（模糊、不分大小寫）尋找檔案，不會檢視檔案內容。與 `search_text` 互補。

# 語法 / 參數規範
* `args` (string, required)：`"檔名關鍵字" 路徑` 或 `路徑 "檔名關鍵字"`（順序容錯，會自動辨識何者為路徑）。
* **安全邊界**：路徑嚴禁為 `/`。

# 執行步驟 (Steps)
1. 接收參數字串，以 `shlex` 拆分並移除誤帶入的 `find` 字樣。
2. 逐一判斷每個參數是否為既存目錄，藉此區分「路徑」與「檔名關鍵字」。
3. 檢查路徑不得為 `/`，否則直接阻斷。
4. 組合為 `find <路徑> -iname *<關鍵字>*`，以 5 秒逾時執行。

# 範例 (Examples)
* `EXECUTE: find_file_cmd.py "Modelfile" .`

# 異常處理 (Edge Cases)
* 缺少參數時回傳 `[ERROR] 缺少參數。請提供要搜尋的檔案名稱與路徑...`。
* 路徑為 `/` 時回傳 `[ERROR] 安全邊界阻斷：嚴禁對全系統根目錄 (/) 執行檔案搜尋...`。
* 找不到符合檔案時回傳 `[PASS] 找不到檔名包含 "..." 的檔案。`（非錯誤，屬正常結果）。
