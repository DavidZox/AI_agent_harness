# 背景 / 運作原理
包裝系統 `grep`，用於在檔案內容中搜尋關鍵字。強制補上 `-r -n -i -I`（遞迴、行號、忽略大小寫、跳過二進位檔）以降低誤用與逾時風險。

# 語法 / 參數規範
* `args` (string, required)：`"關鍵字" 路徑`，例如 `"ERROR" .`。
* **安全邊界**：路徑嚴禁為 `/`（全系統根目錄），必須限制在目前工作目錄（`.`）或特定子資料夾內。

# 執行步驟 (Steps)
1. 接收參數字串，以 `shlex` 拆分並移除誤帶入的 `grep` 字樣。
2. 補齊必要旗標（若使用者未自行指定）。
3. 檢查路徑不得為 `/`，否則直接阻斷。
4. 以 8 秒逾時執行 `grep`。

# 範例 (Examples)
* `EXECUTE: grep_cmd.py "model" .`
* `EXECUTE: grep_cmd.py "ERROR" ./skills_system`

# 異常處理 (Edge Cases)
* 路徑為 `/` 時回傳 `[ERROR] 安全邊界阻斷：嚴禁對全系統根目錄 (/) 執行遞迴搜尋...`。
* 找不到符合內容時回傳 `[PASS] 找不到符合該關鍵字的內容。`（非錯誤，屬正常結果）。
* 搜尋範圍過大導致逾時時回傳 `[ERROR] 搜尋超時！...`，應縮小搜尋範圍後重試。
